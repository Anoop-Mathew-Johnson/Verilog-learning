# Verilog Learning Journey

This repository documents my learning journey in **Verilog, digital logic, and computer architecture**.

The purpose of this repository is to build a structured understanding of digital hardware design, starting from fundamental logic gates and progressing toward more complex systems.

## 🎯 Learning Objectives

* Understand digital logic fundamentals
* Learn Verilog HDL
* Design combinational circuits
* Design sequential circuits
* Understand registers and memory
* Build Arithmetic Logic Units (ALUs)
* Learn Finite State Machines (FSMs)
* Progress toward processor architecture
* Prepare for FPGA and VLSI development
